# 宇宙星塵

把星光握在手裡：用一隻手控制星塵移動、聚成光球，再張手散開。

## 網頁版

[**開啟宇宙星塵**](https://kenjipoon.github.io/stardust/)

使用電腦 Chrome 開啟分享網址，按 **開始鏡頭** 並允許攝影機，即可用手勢互動。也可以按 **滑鼠試玩**，不需要攝影機。

網頁版毋須安裝 Node.js、註冊帳戶或輸入 API key。首次開啟及載入模型需要網絡；模型下載後，辨識工作全部在訪客自己的瀏覽器內完成，鏡頭影像不會傳到 GitHub 或其他伺服器。沒有加入離線快取機制；要可靠地斷網使用，請下載完整專案並使用以下本機啟動方式。

分享時建議用 Chrome 直接開啟網址；通訊軟件內置瀏覽器的鏡頭功能可能受限。第一版以電腦 Chrome 為驗證平台。

## 本機離線版

1. 保留整個 `stardust` 資料夾，雙擊 **啟動宇宙星塵.command**。
2. Chrome 會開啟本機畫面。按 **開始鏡頭**，允許攝影機權限。
3. 將一隻手放進鏡頭小窗，讓手掌與手指完整入鏡。

也可以按 **滑鼠試玩**，毋須開鏡頭：移動滑鼠帶走星塵、按住聚合、放開散開。

下載完整資料夾後，程式已附所有模型與依賴，毋須 npm install、API key、帳戶或訂閱。本機啟動不需要網絡。

## 三個動作

| 動作 | 效果 |
|---|---|
| 慢慢移動手掌 | 星塵跟隨移動，方向與鏡像預覽一致 |
| 拇指與食指捏合，保持片刻 | 星塵聚成光球 |
| 張開四隻手指 | 聚合後的光球散開；持續張手不會連續爆發 |

手離開鏡頭後，星塵會回到自由漂浮。第一版追蹤一隻手；若有多隻手入鏡，可能切換追蹤對象。

## 畫面控制

- **隱藏／顯示小窗**：只改變預覽顯示，手勢辨識繼續運行。
- **全螢幕**：按按鈕進入，再按「退出全螢幕」或 Esc 離開。
- **停止鏡頭**：關閉攝影機及辨識 Worker。
- **停止整個程式**：雙擊 **停止宇宙星塵.command**，或在啟動視窗按 Control+C。程式會通知已開啟的頁面停止鏡頭與辨識。
- 完成後可以關閉星塵分頁與啟動的終端機視窗。

切到其他分頁時會暫停辨識與繪圖；攝影機串流會保留，方便返回後繼續。要完全關閉鏡頭，請使用「停止鏡頭」或停止程式。

## 本機與離線

所有鏡頭影像只在 Chrome 內即時處理，不錄影、不儲存、不上傳。程式不請求咪高峰權限。

啟動檔只建立綁定 `127.0.0.1` 的本機靜態伺服器；預設網址是 `http://127.0.0.1:43127`，該埠被佔用時會選用下一個可用埠。伺服器也提供本機停止通知，不接駁雲端模型或遙測服務。

HTML、JavaScript、WASM、模型、圖示皆在資料夾內；字體使用 Mac 內置字體。請勿單獨移走 `index.html`、`models/` 或 `vendor/`。

## 系統與排錯

- 第一版驗證平台：macOS + Google Chrome；本機需 Node.js 18 或以上。此電腦已有 Node.js，啟動檔會自動尋找一般安裝位置及 NVM 版本。
- **鏡頭權限被拒**：在 Chrome 網址列的網站設定允許攝影機；macOS 如有要求，亦需在「系統設定 → 私隱與保安 → 攝影機」允許 Chrome。
- **鏡頭被佔用**：釋放其他程式使用中的鏡頭，再按「開始鏡頭」，或轉用滑鼠。
- **模型載入失敗**：網頁版請確認網絡正常後再試；本機版請保留整個交付資料夾並重新啟動。模型位於 `models/hand_landmarker.task`。
- **動作唔穩定**：確保光線足夠、背景與手有對比、手指完整入鏡；第一版不需要快速揮動。
- **畫面較慢**：程式會在持續低幀率時由 800 粒降至 400 粒。重新載入會恢復預設粒子數。
- 如果 macOS 未有直接執行 `.command`：可右鍵選「打開」。亦可在終端機進入此資料夾執行 `node server.mjs --open`。

## 原始碼

| 檔案 | 用途 |
|---|---|
| `index.html`、`style.css` | 繁體中文介面、版面與視覺 |
| `src/particles.js` | Canvas 星塵、景深、聚合／散開、幀率降載 |
| `src/gestures.js` | 手掌比例校正、防抖、手勢與追蹤中斷處理 |
| `src/hand-worker.js` | MediaPipe 模型載入與 GPU／CPU 委派 |
| `src/app.js` | 鏡頭生命週期、Worker、滑鼠及 UI 控制 |
| `server.mjs` | 本機伺服器、重複啟動檢查、停止通知 |
| `tests/gestures.test.mjs` | 可重跑的手勢邏輯測試 |
| `assets-manifest.json` | 模型／依賴來源、固定版本及校驗值 |

在此資料夾執行 `node --test tests/*.test.mjs` 可重跑 6 項手勢邏輯測試。完整驗證範圍與限制見 **驗證報告.md**。

## GitHub Pages

本專案為純靜態網站，使用相對路徑載入模組、WASM 與模型，可放在 GitHub Pages 的專案子路徑。Pages 發佈來源為 `main` 分支根目錄，`.nojekyll` 保留靜態檔案。`server.mjs` 及 `.command` 只供下載後在本機執行，網頁版不需要啟動它們。
